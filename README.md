# Enmity

### Introduction

Enmity is an action-adventure Terraria-inspired Minecraft expansion datapack that I've been developing over the years (mostly 2021-2023). While the development is mostly halted and I am not going to port the pack to versions later than 1.19, I occasionally stop by to make fixes and even features if I feel like wanting them.
 
Enmity is multiplayer-friendly and will also work on Vanilla servers. Have fun!
    
### Installation guide

1. Download and install OptiFine (some things will break without OptiFine).
2. Install and enable [the resource pack](https://github.com/rzesm/enmity-resources). Optionally you can also get the full pack with some [non-mandatory resources](https://github.com/rzesm/enmity-full-pack) I've made for the expansion.
3. During new world creation:
    - Install Enmity. (Place the archive in the datapacks folder.)
    - Download and install [Terralith v2.2.1a](https://www.curseforge.com/minecraft/mc-mods/terralith/files).
    - Make sure that Enmity is on the top in the datapack selection menu.
    
**Required or recommended client settings:**
- Particles must be enabled. *(Options -> Video Settings -> Animations -> All ON)*
- Fabulous Graphics are recommended. *(Options -> Video Settings -> Graphics: Fabulous)*
- OptiFine's Dynamic Lights feature should be enabled. *(Options -> Video Settings -> Dynamic Lights: Fancy/Fast)*

**Some incompatibilities worth of noting:**
- Using Enmity alongside other datapacks may cause problems.
- Running Enmity on servers with engines other than Vanilla is very likely not to work well.
- Some OptiFine shader packs will interfere with Enmity's pitch black darkness (the lightmap). Make sure the pack you want to use doesn't cause that conflict.
- I have no clue how Enmity will behave when mixed with mods.
